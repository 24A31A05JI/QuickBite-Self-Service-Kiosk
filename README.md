# 🍔 QuickBite – Self-Service Restaurant Kiosk

A modern self-service restaurant kiosk designed to make food ordering faster, easier, and more convenient.

## 🚀 Live Demo

👉 [Click here to use QuickBite](https://24a31a05ji.github.io/QuickBite-Self-Service-Kiosk/)

## ✨ Features

- 🍔 Interactive restaurant menu
- 🛒 Add items to cart
- 💰 Order total calculation
- 🎫 Self-service ordering experience
- 📱 Responsive user interface
- ⚡ Simple and user-friendly design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🎯 Project Objective

QuickBite aims to reduce waiting time in restaurants by allowing customers to browse the menu, select their food, and place orders through a self-service kiosk.
