#🥘 QuickBite — Self-Service Restaurant Ordering Kiosk

### A Modern, Interactive Restaurant Ordering Experience

QuickBite is a web-based self-service restaurant ordering kiosk designed to make food ordering simple, interactive, and convenient.

Customers can browse a digital menu, explore food categories, customize their selections, manage their cart, and experience a simulated checkout process through an intuitive interface.

**🌐 [View Live Demo](https://24a31a05ji.github.io/QuickBite-Self-Service-Kiosk/)**

---

## ✨ Key Features

- **Interactive Digital Menu** — Browse 42 food items across seven categories.
- **Food Categories** — Burgers, Pizza, Pasta, Biryani, Sides, Beverages, and Desserts.
- **Food Search** — Quickly find menu items using the search feature.
- **Food Customization** — Personalize orders using available customization options.
- **Shopping Cart** — Add items, update quantities, remove items, and view totals.
- **GST Calculation** — Display tax calculations during checkout.
- **Demo Checkout** — Experience a simulated ordering and payment flow.
- **Order Confirmation** — Display an order confirmation after checkout.
- **Modern User Interface** — Dark charcoal and gold styling with food photography.

## 🚀 Getting Started

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the Live Server extension.
4. Browse the menu and explore the ordering experience.

No backend installation or database setup is required for this frontend demonstration.

## 🧭 How It Works

1. **Explore the Menu:** Browse dishes by category or search for a specific item.
2. **Select Food:** View dish details and choose available customization options.
3. **Manage the Cart:** Add or remove items and adjust quantities.
4. **Review the Bill:** View item totals, applicable GST, and the final amount.
5. **Complete Demo Checkout:** Proceed through the simulated checkout flow.
6. **Receive Confirmation:** View the order confirmation screen.

## 🎯 Project Objective

The objective of QuickBite is to demonstrate how a digital self-service interface can simplify restaurant ordering and provide customers with greater control over their selections.

The project explores the frontend experience of a restaurant kiosk, including menu discovery, order customization, cart interactions, and checkout.

## ⚠️ Project Scope

QuickBite is currently a **frontend demonstration project**.

- Checkout is simulated.
- No real payments are processed.
- Orders are not transmitted to a restaurant.
- A backend database and restaurant management dashboard are not included.
